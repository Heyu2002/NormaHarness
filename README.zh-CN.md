# Norma Harness

**简体中文** · [English](./README.md) · [ForAGENTS：开发指南](./ForAGENTS.md)

Norma Harness 是一个让同一进程内的多个独立 Agent 协作的 Rust 框架，并提供可直接运行的本地聊天室。每个参与者叫作 **Resident**：它可以是一个 LLM、聊天房间协调器，也可以是提供工具的服务。Resident 自己管理工作和状态，框架负责发现它们，并把消息送到正确的参与者。

如果你想让不同模型在同一聊天室里分别思考、互相点名继续讨论，同时又希望以后能接入自己的 Agent，这个项目提供了一个可运行的起点。

## 现在能做什么

| 能力 | 使用时会发生什么 |
| --- | --- |
| 单聊与群聊 | 点击在线模型直接单聊；选择至少两个模型创建群聊。当前网页启动 GPT-6 Luna 和独立的 GPT-5.6 Luna Resident。 |
| 并行回答与接力 | 群聊中没有单独 @ 某个模型时，所有成员同时开始回答；@ 指定成员时，先由指定成员回答。模型可以 @ 其他模型继续讨论，以 `@你` 开头给出面向用户的完整答案。 |
| 模型主动取上下文 | 当前 Codex Resident 收到房间通知后，用 `read_chat_context` 读取真实消息，而不是依赖网页把整段 JSON 历史塞进用户消息。它还可以查询群成员、按需读取长期记忆。 |
| 图片与 GIF | 可以发送 PNG、JPEG、WebP、GIF；模型生成的图片可作为可预览、可下载的聊天附件发布。 |
| 历史与归档 | 普通聊天和附件保存在本机；关闭页面或服务重启后仍可继续。归档聊天在“设置”弹窗中搜索、筛选和恢复。 |
| 无痕与长期记忆 | 新会话可统一选择无痕模式，不写入 Norma 的聊天快照或长期记忆。长期记忆默认关闭，开启后会在房间休眠或模型上下文压缩时提取。 |

## 这套方式值得探索的地方

**参与者可以独立演进。** 聊天室按能力寻找 LLM Resident；新的模型实现只要遵守共享对话协议，就能加入，而不必变成框架内部的特殊分支。框架同样不接管模型的线程、重试或业务状态。

**协作不被固定成一条回答流水线。** 群成员先并行给出各自判断，再通过 @ 提及触发后续交流。一个模型认为答案已经完整时，可以直接面向用户作答。这样既能得到不同模型的独立观点，也能让讨论继续推进。

**上下文由工具按需提供。** 模型面对的是房间通知与可调用的工具；聊天记录、群成员和附件各有明确的提供者。读取历史时会检查房间成员身份、当前轮次可见范围以及无痕边界。这种方式便于扩展更多工具，也便于检查模型究竟看到了什么。

底层只有两条通路：**RDF** 负责注册和能力发现，**RTDF** 负责 Resident 之间的一跳消息投递。业务规则留给各 Resident，因而同一套底座也可以连接聊天以外的服务。

## 本地运行

需要 Rust **1.85+**、已安装并登录的 Codex CLI，以及能够使用上述模型的本机账号。先执行 `codex login`，然后在仓库根目录运行：

```console
cargo run -p norma-web
```

在本机打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。网页默认监听所有 IPv4 网卡；目前没有网站用户认证，因此只应在可信网络开放。若只想本机访问：

```console
NORMA_WEB_BIND=127.0.0.1:3000 cargo run -p norma-web
```

上面的环境变量写法适用于类 Unix Shell；在 PowerShell 中可先执行 `$env:NORMA_WEB_BIND = "127.0.0.1:3000"`，再运行 `cargo run -p norma-web`。

进入网页后，可以直接点击模型开始单聊；在“创建群聊”中选择两个模型试试无 @、@ 单个模型和模型之间互相提及的效果。“创建群聊”下方的“无痕模式”只影响之后新开的会话，已有房间保持原来的模式。

普通房间、消息、附件与模型会话映射保存在本机。Windows 默认使用 `%LOCALAPPDATA%\NormaHarness`，其他系统使用 XDG/HOME 数据目录；`NORMA_DATA_DIR` 可以改存储位置。无痕只约束 Norma 自己的持久化，模型提供方和操作系统仍可能保留处理记录。

常用配置：

| 环境变量 | 作用 |
| --- | --- |
| `NORMA_WEB_BIND` | 网站监听地址；默认 `0.0.0.0:3000`。 |
| `NORMA_CODEX_CWD` | Codex Resident 使用的工作目录；默认当前目录。 |
| `NORMA_CODEX_EFFORT` | 覆盖本机 Codex 的推理强度。 |
| `NORMA_CODEX_WORKSPACE_WRITE=1` | 允许 Codex 修改所选工作目录；默认只读。 |
| `NORMA_DATA_DIR` | 普通聊天、媒体、记忆和模型会话映射的本地目录。 |

## 把它作为框架使用

`norma-harness` 是注册与消息投递库；`norma-residents` 提供 Codex、聊天室和工具 Resident 的具体实现。可以先运行一个不启动网页的[往返示例](./residents/examples/roundtrip.rs)：

```console
cargo run -p norma-residents --example roundtrip -- . "用一句话概括这个仓库。"
```

想接入新的 Resident、修改工具或理解框架约束，请看 [ForAGENTS.md](./ForAGENTS.md)。更完整的所有权与注册/投递不变量见 [架构说明](./docs/ARCHITECTURE.md)；具体 Codex Resident 的协议见 [residents/README.md](./residents/README.md)。

项目使用 Apache-2.0 许可证。
